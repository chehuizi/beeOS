🎯 3 大设计原则（铁律）

1. 私有化优先

所有组件默认不出门。唯一外发流量是模型 API 调用（可走客户内网代理）。

2. 1 人天部署

4 个 native systemd unit + 源码 tarball + uv pip install。零 Docker，零 K8s。 bash scripts/deploy-to-ecs.sh

3. 模型中立 AB

litellm 抽象层 + DeepSeek + 通义 双供应商在线 AB。单一故障 30 分钟切走。

🔑 关键约束（M1）

  • 状态机：5 状态（Queued / Running / AwaitingHuman / Done / Failed）
  • 审计：哈希链 SHA-256(prev_hash + JSON(payload))，5 年保留
  • 凭证：AES-256-GCM 加密，主密钥从 BEEOOS_MASTER_KEY 读取
  • DB schema：lifespan 启动时 Base.metadata.create_all（V1+ 改 Alembic）
  • 注入检测：Guardian 8 条正则匹配，score > 0.7 拒绝
