## 痛点 + 时机

**痛点**：

- 中国 500 万家小会计师事务所 / 代账公司 / 律所，长期面临"专家经验流失"和"人力成本上涨"双重压力
- 巨头的 AI 助手（ChatGPT / 钉钉 / 扣子）= 公有云 SaaS，**客户敏感数据不敢上传**
- 企业 AI 厂商（IBM / UiPath）= 百万级私有部署，**小所付不起、用不动**

**时机**（2026 为什么必须现在做）：

- DeepSeek / 通义开源 LLM 让 token 成本降到 ¥0.5/任务，**私有化部署经济性首次成立**
- MCP 协议成熟，多模型 AB 切换有标准
- 行业经验：3 年 OpenAI 应用 + 1 年大模型项目踩坑

---

## 我们做什么

**beeOS = 行业 Box 模板 + 私有化部署平台**

- **行业 Box**：把"会计月结"这个场景的所有技能、知识、凭证封装成 `MonthCloseBox`，开箱即用
- **私有化部署**：客户服务器上跑，**数据不出门**，合规友好
- **多模型 AB**：DeepSeek + 通义双供应商，单一故障 30 分钟切走

**MVP 第一个 Box = MonthCloseBox**（小会计所月结自动化），目标：

- 月结时间从 5 天 → 1 天
- 财务人员从 8 人 → 5 人
- 单客户 ROI：1 个 sister 节省 ¥10 万 / 年

## 商业模式

| 层级 | 定价 | 客单价 |
|---|---|---|
| 平台订阅 | ¥3-8 万 / 年 | 含 Core + 商业 License |
| 行业 Box | ¥1-3 万 / 盒 / 年 | 模板包 |
| Premium 支持 | ¥1-5 万 / 年 | 7×24 响应 |
| 培训认证 | ¥2-5 千 / 人 | 一次性 |

**Y1 目标**：10 个付费客户 / ¥50 万 ARR / M9 现金流回正

**核心数字**：

- 单客户成本：¥4 万 / 年（模型 ¥100 + 摊销 ¥4 万）
- 单客户毛利：18%（Y1）→ 50%+（规模化）
- LTV/CAC：30-50（健康）
- 盈亏平衡：10 个付费客户（M5-M6）
