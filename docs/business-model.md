# beeOS 商业模式

> **状态**：v0.1 草稿 · 待迭代
> **日期**：2026-08-07

## TL;DR

beeOS 定位为 **"AI 数字员工私有化部署平台，专为 50-500 人专业服务公司（会计师事务所、律所、咨询、私营医院）开箱即用"**。

切入点是 **小会计师事务所**——通过 **MonthCloseBox（月结自动化）** 等行业模板，让会计所的资深员工变成"管 3 个人的 Bee"，最终把人效从 1× 拉到 3×。

**Y1 目标**：10 个付费客户 / ¥50 万 ARR。**Runway**：12 个月。

---

## 0. 定位一句话

**"AI 数字员工私有化部署平台，专为 50-500 人专业服务公司（会计师事务所、律所、咨询、私营医院）开箱即用"**

市场空白点：巨头（OpenAI / 钉钉 / 阿里）做"通用 SaaS 大市场"，企业 AI 厂商（IBM / UiPath）做"大客户长周期"，**中间这片 50-500 人专业服务公司既付不起大客户的钱，也不愿把客户数据上公有云**。

---

## 1. 客户细分（CS）

按"垂直行业 × 工种"切，**MVP 阶段只选 1 个**：

| 候选 | 痛点 | Box 模板示例 | 监管 |
|---|---|---|---|
| **小会计师事务所** ⭐ 首选 | 月结、报税、审计底稿 | TaxBox / AuditBox / ReconciliationBox | 较松 |
| **小律所** | 合同审查、尽调、文档脱敏 | ContractBox / DDBox | 较松 |
| **财务咨询 / 代账** | 多客户并行记账、关账 | MonthCloseBox | 较松 |
| **民营医院 / 连锁诊所** | 病历结构化、医保对账 | MedicalBox / InsuranceBox | **严**（先避开） |

**首选会计所**的理由：

- 流程标准化，模板可复用性高
- 监管相对友好（数据可上私有化服务器）
- 付费意愿强（已有 SaaS 付费习惯，如金蝶 / 用友）
- 痛点高频月结（每月必做）

---

## 2. 价值主张（VP）

针对"专业服务 SMB"：

- ✅ **专家经验沉淀**：把资深员工 70% 的重复工作固化为可复用 Box，离职不带走
- ✅ **数据不出门**：私有化部署，客户合同 / 财务数据不出机房
- ✅ **开箱即用**：不需要招 AI 工程师，行业 Box 模板即装即用
- ✅ **节省人力**：1 个资深员工 + Bee = 3 个人的产出

**核心 KPI（客户视角）**：月结时间从 5 天 → 1 天；财务人员从 8 人 → 5 人。

---

## 3. 渠道通路（CH）

**小团队 + 私有化**，**禁用重销售 / 招投标 / 大客户 BD**。渠道选择：

| 渠道 | 用途 | 优先级 |
|---|---|---|
| **GitHub 开源 BeeOS Core** | 引流 + 社区贡献 + 品牌 | P0 |
| **垂直行业 KOL**（如本地会计师协会讲师） | 首批付费用户 | P0 |
| **云厂商 Marketplace**（阿里云 / 腾讯云 / 华为云） | 镜像一键部署 + 流量 | P1 |
| **行业垂直 SaaS 嵌入**（金蝶 / 用友 / 钉钉） | 流量入口 | P2 |
| **内容营销**（知乎 / 公众号「小所 AI 转型」系列） | SEO + 信任建立 | P1 |
| **口碑转介绍** | 付费转化主力 | P1 |

**NG 渠道**：电话销售、招投标、政府关系、大客户直销。

---

## 4. 客户关系（CR）

**自助 + 轻售后**：

- **评估期**：免费试用 30 天 + 在线文档 + 社区 Discord
- **付费期**：在线工单 + 30 天 email 支持 + 季度回访
- **企业版**：银 / 金 / 铂金支持包（4h / 8h / 24h 响应）

**不做**：驻场实施、定制开发（除非按项目计费作为额外服务）。

---

## 5. 收入来源（RS）

**小团队 + 私有化**的现金流模型必须**轻订阅 + 模板付费**：

| 收入项 | 定价 | 目标客户 |
|---|---|---|
| **BeeOS Core（开源）** | 免费 | 开发者 / 社区 |
| **BeeOS Enterprise 订阅** | **¥3-8 万 / 年 / 实例**（含商业 license + 更新 + 标准支持） | SMB 付费客户 |
| **行业 Box 模板包** | **¥1-3 万 / 盒 / 年** 或一次性买断 ¥2-5 万 | 模板采购 |
| **Premium 支持** | **¥1-5 万 / 年**（4h / 8h / 24h 响应） | 中型客户 |
| **Workshop SDK 商业版** | **¥1 万 / 年 / 开发者** | 集成商 / 二次开发者 |
| **培训认证** | **¥2-5 千元 / 人** | 客户技术团队 |

**核心 ARR 目标（Y1）**：找到 10 个付费客户 × ¥5 万 = **¥50 万 ARR**。

**单点回本模型**：1 个客户 ¥5 万 / 年，**获客成本必须 < ¥1 万**（如果走 GitHub + 内容，理论上接近 0）。

---

## 6. 关键资源（KR）

- **核心代码**：BeeOS Core（开源）+ 行业 Box（闭源）
- **行业 Know-how**：必须找 1 个会计所合伙人做长期顾问（股权 or 顾问费）
- **大模型 API**：DeepSeek / 通义 / 智谱（**至少 2 家做 AB 切换防锁定**）
- **部署工具链**：Helm chart、Docker compose、Terraform（让 1 个客户实施 < 1 人天）

---

## 7. 关键活动（KA）

按优先级（影响 PMF）：

1. **行业 Box 模板研发**（月结 / 审计 / 报税）—— **40% 时间**
2. **BeeOS Core 平台打磨**（Queen / Bee / BeeBox 十巧板）—— **30% 时间**
3. **种子客户获取**（GitHub + KOL）—— **15% 时间**
4. **内容营销**（公众号 / 知乎）—— **10% 时间**
5. **运营 + 行政**—— **5% 时间**

## 9. 成本结构（CS）

**Y1 烧钱估算（独立开发者 / 小团队）**：

| 项 | 金额（月） |
|---|---|
| 创始人生活费（1-2 人） | ¥1-2 万 |
| 模型 API 成本（自用 + 客户用） | ¥0.5-1 万 |
| 云资源（开发 + demo） | ¥0.1-0.3 万 |
| 行业顾问费 | ¥0.5 万 |
| 营销（内容 / SEO） | ¥0.1-0.3 万 |
| 工具 / 办公 | ¥0.1 万 |
| **合计** | **¥2.5-4 万 / 月** |

**Runway**：如果自有 ¥30 万，**顶多烧 12 个月**——**12 个月必须验证 PMF**。

## 10. MVP 路线图（3 阶段）

### Phase 1：验证"专业服务 SMB 愿意为私有化 AI 付费"（M1-M3）

- 选定 **小会计所** 为切入点
- 做出 **1 个 BeeBox = MonthCloseBox**（月结自动化）
- 找 **3 家种子客户** 免费试用（换案例 + 反馈）
- **不卖货，只验证**：他们愿不愿意未来付费？

**Kill 条件**：3 家里 0 家愿意付费 → 切换行业（如律所）；切换后仍 0 → 转型。

### Phase 2：跑通"付费 + 模板复用"（M4-M6）

- 上线 **3 个 Box**（月结 + 报税 + 审计底稿）
- 启动 **¥5 万 / 年订阅** + **Box 模板费**
- 目标：**5-10 个付费客户 / ¥25-50 万 ARR**
- 开源 BeeOS Core 推 GitHub

### Phase 3：扩张"行业 + 模板"（M7-M12）

- 拓展到 **律所 / 咨询**（跨行业复用平台）
- 上线 **Workshop 模板市场**（让客户自定义 Box）
- 目标：**30 个付费客户 / ¥150 万 ARR**
- 启动小笔种子融资（如需要）

## 11. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| **SMB 付费意愿低** | 高 | 早期做"按结果付费"试点，按节省工时分成 |
| **模型 API 涨价** | 中 | 本地小模型备份 + 多供应商 AB |
| **私有化部署运维重** | 高 | 极限自动化：1 人天完成从合同到生产部署 |
| **行业 Know-how 不足** | 高 | 借力顾问 + 种子客户共创 |
| **巨头下场碾压** | 中 | 死守"私有化 + 长尾"细分，巨头不屑 |
| **合规踩雷**（医疗 / 金融） | 中 | 早期只做会计所（监管友好），避开医疗 |
| **创始团队 burnout** | 高 | 12 个月硬截止，不行就转型 |

---

## 12. 待决策项（必答）

1. **你本人是会计 / 律师 / 医生背景吗？** 如果不是，必须在 30 天内找到一个行业合伙人
2. **你愿意自己掏 30 万烧 12 个月吗？** 如果不愿意，需要先拿外部资金
3. **你能不能介绍到 3 家会计所合伙人？** 如果不能，行业 KOL 渠道要重新设计
